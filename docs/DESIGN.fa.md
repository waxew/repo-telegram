# طراحی ظاهری و تجربه کاربری

## اصل طراحی

ویدئوی مرجع یک Mini App یا وب‌سایت جداگانه نیست؛ رابط آن از پیام‌ها، عکس‌ها، Reply Keyboard و Inline Keyboard خود تلگرام تشکیل شده است. به همین دلیل کپی درست ظاهر، یعنی ساخت همان سلسله‌مراتب پیام و دکمه با API بومی تلگرام.

## اجزای بصری

- Reply Keyboard اصلی همیشه کوچک و ماندگار (`resize_keyboard` و `is_persistent`) است.
- گزینه‌های اصلی با `primary` آبی، تأیید با `success` سبز و عملیات مخرب با `danger` قرمز تعریف شده‌اند.
- کارت محصول شامل عکس اول، نام، توضیح، وضعیت موجودی و دکمه سبز هر پلن است.
- فاکتور خرید، محصول، پلن، قیمت، تخفیف و مبلغ نهایی را قبل از کسر موجودی نشان می‌دهد.
- تمام آیکن‌ها همان سبک ایموجی ویدئو را دنبال می‌کنند تا در تم روشن و تاریک تلگرام خوانا باشند.
- پیام‌ها با HTML Telegram قالب‌بندی می‌شوند و متن واردشده توسط مدیر/کاربر پیش از نمایش escape می‌شود.

## محل تغییر طراحی

- همه‌ی نوشته‌ها و نام دکمه‌ها: `src/ui/texts.ts`
- ترتیب ردیف‌ها، رنگ‌ها و callbackها: `src/ui/keyboards.ts`
- کارت و فاکتور محصول: `productCaption` و `invoiceText` در `src/ui/texts.ts`
- صفحه‌ی مرورگر پرداخت: CSS توضیح‌دار داخل `src/lib/zarinpal.ts`
- تصویر شروع نمونه: `assets/default-start.svg`

## ویرایش تصویر SVG

فایل SVG متن‌باز است و هر بخش آن کامنت دارد. رنگ پس‌زمینه، کارت مرکزی، آیکن کیف خرید و متن را می‌توان بدون افت کیفیت در Figma، Illustrator، Inkscape یا حتی ویرایشگر متن تغییر داد. پس از خروجی PNG/JPG، مدیر همان تصویر را داخل «تنظیم عکس استارت» می‌فرستد؛ ربات `file_id` را ذخیره می‌کند.

## محدودیت تطابق پیکسلی

فونت، گوشه دکمه، اندازه ایموجی و فاصله‌ی Reply Keyboard را خود کلاینت Telegram تعیین می‌کند. بنابراین روی همان نسخه‌ی تلگرام ظاهر بسیار نزدیک به ویدئو است، اما یک فایل CSS نمی‌تواند ظاهر native را روی همه دستگاه‌ها پیکسل‌به‌پیکسل اجبار کند. داده، ترتیب، رنگ معنایی و رفتار دکمه‌ها در سورس ثابت‌اند.
