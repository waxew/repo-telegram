# قابلیت‌های قابل افزودن و کمبودهای فعلی

این فایل جداگانه همان بخشی است که مشخص می‌کند نسخه‌ی فعلی بعداً چگونه می‌تواند کامل‌تر شود.

## موارد مهم برای نسخه بعد

1. **پرداخت خودکار اشتراک ربات‌ساز مرکزی**: دکمه تمدید فعلاً کاربر را به پشتیبانی هدایت می‌کند. می‌توان پلن ماهانه/سالانه، فاکتور و فعال‌سازی خودکار `subscription_ends_at` را اضافه کرد.
2. **پنل وب یا Telegram Mini App**: مدیریت تعداد زیاد محصول در چت زمان‌بر است. Mini App می‌تواند جدول، Drag & Drop، نمودار و آپلود گروهی داشته باشد.
3. **موجودی انبار و SKU**: نسخه فعلی وضعیت موجود/ناموجود دارد، اما شمارش موجودی، رزرو سبد و هشدار کمبود ندارد.
4. **سبد خرید چندمحصولی**: جریان فعلی مانند ویدئو خرید مستقیم یک پلن است. سبد، هزینه ارسال و آدرس پستی قابل افزودن‌اند.
5. **تأیید حذف دو مرحله‌ای**: حذف محصول، پلن، دسته و تخفیف اکنون با یک دکمه مدیر انجام می‌شود؛ می‌توان دکمه تأیید/لغو اضافه کرد.
6. **پاسخ رشته‌ای تیکت پشتیبانی**: پیام کاربر فوروارد می‌شود و مدیر با ابزار پیام مستقیم پاسخ می‌دهد. نگاشت reply خودکار بین گروه پشتیبانی و کاربر می‌تواند تجربه را بهتر کند.
7. **زمان‌بندی و توقف Broadcast**: صف فعلی ارسال را گروه‌گروه انجام می‌دهد. زمان‌بندی آینده، pause/resume، گزارش نهایی و rate-limit تطبیقی قابل افزودن است.
8. **چند ادمین و نقش‌ها**: نسخه فعلی مالک و یک ادمین دوم دارد. نقش‌های مالی، محصول، پشتیبانی و فقط‌خواندنی برای تیم‌ها مفید است.
9. **وبهوک سفارش و API عمومی**: اتصال به CRM، حسابداری، انبار و سرویس صدور لایسنس با event/outbox امضاشده.
10. **چندزبانگی واقعی**: نام انگلیسی محصول ذخیره می‌شود، اما کل UI فارسی است. زبان کاربر و ترجمه همه پیام‌ها قابل اضافه‌شدن است.
11. **گزارش مالی پیشرفته**: خروجی CSV/Excel، نمودار فروش، سود، بازپرداخت و تسویه.
12. **حفاظت ضدتقلب**: محدودیت تلاش کد تخفیف، rate-limit per user، لیست مسدود و بررسی رفتار غیرعادی.
13. **بکاپ زمان‌بندی‌شده**: ارسال دوره‌ای فایل رمز‌شده به R2 یا Storage و آزمون خودکار بازیابی.
14. **تست end-to-end Telegram**: محیط staging با Bot token آزمایشی برای تست واقعی webhook، فایل و callback.
15. **High Availability برای Broadcast**: صف Cloudflare Queues و Durable Object برای مقیاس بسیار بزرگ.

## محدودیت‌های آگاهانه نسخه فعلی

- ظاهر native تلگرام بین دستگاه‌ها اندکی فرق می‌کند و پیکسل‌به‌پیکسل قابل کنترل نیست.
- کاربر باید قبل از پیام مستقیم، حداقل یک‌بار ربات فروشگاه را Start کرده باشد؛ این محدودیت Telegram است.
- `file_id` رسانه فقط توسط همان ربات قابل استفاده است؛ انتقال محصول بین دو ربات نیازمند دانلود/آپلود یا رسانه‌ی مشترک است.
- ایجاد واقعی فروشگاه تا زمانی که توکن مرکزی BotFather و secretهای Cloudflare تنظیم نشوند فعال نمی‌شود.
- برای استفاده زرین‌پال، مالک هر فروشگاه باید مرچنت‌کد معتبر و شرایط پذیرندگی فعال داشته باشد.
